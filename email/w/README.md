# Hospital patient message portal

This is a frontend-only demo. Login accepts any valid email address and a non-empty password; it does not authenticate a real account. Patient messages are saved in the current browser's local storage. They are not sent to a server or by email.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

Messages remain in that browser after a reload. Clearing browser storage or using another browser/device removes or will not show those messages.
